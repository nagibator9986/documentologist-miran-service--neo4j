# External Integrations

## Databases

### PostgreSQL `16-alpine`
- **Role:** Relational persistence and Prefect orchestration backend
- **Connection:** `postgresql+asyncpg://<user>:<password>@postgres:5432/<db>` (async); `postgresql://...` (sync/Alembic)
- **Databases provisioned on first start** (via `scripts/init-db.sql`):
  - `ocr_service` — OCR job state, document metadata (used by `ocr-api` and `ocr-worker`)
  - `agent_memory` — long-term conversation memory (used by `langgraph-agent`)
  - `prefect` — Prefect server internal state
- **ORM / migrations:** SQLAlchemy 2 async + Alembic (OCR service)
- **Drivers:** `asyncpg>=0.29` (async), `psycopg2-binary>=2.9` (sync)
- **Config keys:** `DATABASE_URL`, `DATABASE_URL_SYNC`, `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DSN`
- **Host port:** `127.0.0.1:5434 → 5432`

---

### Neo4j `5.20` (with APOC plugin)
- **Role:** Knowledge graph — documents, sections, entities, and their relationships; supports graph-enriched RAG retrieval
- **Protocol:** Bolt (`bolt://neo4j:7687`)
- **Driver:** `neo4j>=5.0.0` (Python official driver)
- **Used by:** `langgraph-agent` (graph queries via `app/tools/neo4j_query.py`), `bank-knowledge` indexer (graph ingestion)
- **Config keys:** `NEO4J_URI`, `NEO4J_USER`, `NEO4J_PASSWORD`, `NEO4J_MAX_CONNECTION_POOL_SIZE` (default 50)
- **Internal fulltext index:** `sectionText` on `Section.text_preview`
- **Host ports:** `127.0.0.1:7475 → 7474` (HTTP browser), `127.0.0.1:7688 → 7687` (Bolt)

---

### Qdrant (vector database)
- **Role:** Dense vector storage and approximate nearest-neighbour search for document chunks
- **Collection:** `bank_knowledge` (default), 1024-dimensional vectors (bge-m3 embeddings)
- **Named vector key:** `q_vec` (dual-vector collection schema set by the indexer)
- **Client:** `qdrant-client>=1.9.0`
- **Used by:** `langgraph-agent` (hybrid vector + BM25 search), `bank-knowledge` indexer (upsert chunks)
- **Config keys:** `QDRANT_URL`, `QDRANT_COLLECTION`, `QDRANT_VECTOR_SIZE`, `QDRANT_TOP_K` (default 40), `QDRANT_API_KEY` (optional, for Qdrant Cloud)
- **Host ports:** `127.0.0.1:6335 → 6333` (HTTP/REST), `127.0.0.1:6336 → 6334` (gRPC)

---

### Redis `7-alpine`
- **Role (primary):** Short-term session/conversation memory in `langgraph-agent`; session TTL default 3600 s
- **Role (secondary):** Rate-limiting backend for `slowapi` (multi-replica safe via `limits[redis]`)
- **Client:** `redis>=5.0.0`
- **Config keys:** `REDIS_URL` (format: `redis://:<password>@redis:6379`), `REDIS_PASSWORD` (optional), `SESSION_TTL_SECONDS`
- **Host port:** `127.0.0.1:6380 → 6379`

---

## Object Storage

### MinIO (S3-compatible)
- **Role:** Binary object storage for all pipeline stages
- **Buckets** (created automatically by `minio-init` container):
  - `source-files` — raw uploaded PDFs/images (written by `ocr-api`)
  - `analysis-results` — Surya OCR JSON output (written by `ocr-worker`, read by `bank-knowledge`)
  - `agent-exports` — DOCX/PDF exports generated by `langgraph-agent`
- **Client:** `minio>=7.2.0` (Python MinIO SDK)
- **Config keys:** `MINIO_ENDPOINT`, `MINIO_ACCESS_KEY`, `MINIO_SECRET_KEY`, `MINIO_SECURE`, `MINIO_PUBLIC_ENDPOINT` (for presigned browser-accessible URLs)
- **Also used by:** MLflow artifact storage (via `boto3>=1.34.0` S3 compatibility layer)
- **Host ports:** `127.0.0.1:9002 → 9000` (API), `127.0.0.1:9003 → 9001` (web console)

---

## Local LLM / Embedding Server

### Ollama
- **Role:** Hosts all LLM and embedding models locally; GPU inference on the host machine
- **Access pattern:** Containers reach Ollama on the Docker host via `http://host.docker.internal:11434`
- **Models in use:**
  - `qwen2.5:14b` — primary chat/reasoning model (langgraph-agent default)
  - `qwen2.5:7b` — secondary/draft generation model and bank-knowledge chat
  - `bge-m3:latest` — multilingual dense embedding model (1024-dim); used by both `bank-knowledge` indexer and `langgraph-agent`
- **Integration libraries:** `langchain-ollama>=0.2.0`
- **Config keys:** `OLLAMA_URL`, `OLLAMA_MODEL`, `OLLAMA_EMBEDDING_MODEL`, `OLLAMA_GENERATE_DRAFT_MODEL`, `OLLAMA_TIMEOUT`

## Workflow Orchestration

### Prefect `3-latest`
- **Role:** Task orchestration for OCR pipeline jobs (submit, retry, concurrency control)
- **Server:** Self-hosted (`prefecthq/prefect:3-latest`), backed by the `prefect` PostgreSQL database
- **Client library:** `prefect>=3.0, <4` (OCR service); `prefect>=2.14` (legacy bank_knowledge UI)
- **Config key:** `PREFECT_API_URL` (e.g., `http://prefect-server:4200/api`)
- **Host port:** `127.0.0.1:4201 → 4200`

---

## HuggingFace Model Hub

- **Role:** Source for cross-encoder reranker weights
- **Models downloaded at image build time** (baked into the `langgraph-agent` Docker layer):
  - `cross-encoder/mmarco-mMiniLMv2-L12-H384-v1` — primary multilingual reranker (13 languages incl. Russian/Kazakh)
  - `cross-encoder/ms-marco-MiniLM-L6-v2` — fallback reranker
- **Cache path inside container:** `/root/.cache/huggingface` (`HF_HOME`, `TRANSFORMERS_CACHE`)
- **Library:** `sentence-transformers>=2.7.0`

---

## Observability

### MLflow (optional)
- **Role:** LLM tracing, prompt registry, run metrics
- **Enabled via:** `MLFLOW_ENABLED=true` (default `false` — all tracing code is a no-op when disabled)
- **Config keys:** `MLFLOW_TRACKING_URI` (default `http://localhost:5000`), `MLFLOW_EXPERIMENT_NAME` (default `miran-agent`)
- **Artifact storage:** MinIO/S3 via `boto3>=1.34.0`
- Note: MLflow server is **not** defined in `docker-compose.yml`; it must be stood up separately if enabled.

### Prometheus
- **Role:** Metrics scraping endpoint on `ocr-api`
- **Library:** `prometheus-client>=0.20, <1`

## Internal HTTP Integrations (Inter-Service)

| Caller | Target | Config Key | Purpose |
|---|---|---|---|
| `ocr-worker` | `bank-knowledge` | `INDEXER_WEBHOOK_URL` | POST after OCR completes to trigger chunk → embed → index pipeline |
| `ocr-api` | `bank-knowledge` | `INDEXER_STATUS_URL` | GET `/{doc_id}/status` to poll indexing progress |
| `ocr-api` / `ocr-worker` | `bank-knowledge` | `WEBHOOK_SECRET` | HMAC-SHA256 webhook request signing (optional) |
| `langgraph-agent` | `ocr-api` | `OCR_SERVICE_URL` | Upload documents for OCR ingestion |
| `chainlit-ui` | `langgraph-agent` | `AGENT_URL` | HTTP proxy to agent REST/SSE API |

- Inter-service communication uses Docker internal DNS names (e.g., `ocr-api:8000`, `bank-knowledge:8002`)
- All services share the `miran-net` bridge network

## GPU / NVIDIA

- **NVIDIA Container Toolkit** — passes GPU device into `ocr-worker`, `bank-knowledge`, `langgraph-agent`
- **CUDA 12.1** — bundled inside PyTorch wheels; no system CUDA install required on the host
- **Config keys:** `NVIDIA_VISIBLE_DEVICES` (default `all`), `NVIDIA_DRIVER_CAPABILITIES`
- **Minimum host driver:** `>=525`
