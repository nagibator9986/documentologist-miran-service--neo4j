  <action>
    Create `tests/eval/run_eval.py` — a standalone Python script (NOT a pytest test) that:

    1. **Loads dataset** from `tests/eval/dataset.json` (relative to script location using `Path(__file__).parent`).

    2. **Runs each query** against `POST /api/v1/chat/` via httpx.Client (synchronous). For each entry:
       - Send `{"query": entry["query"], "session_id": f"eval-{entry['id']}"}` to the chat endpoint
       - Timeout per query: 120 seconds
       - On timeout or HTTP error: record as error, continue to next query (do NOT abort)
       - Record: status_code, response intent, elapsed time, response body

    3. **Evaluate each result** against expected outcomes:
       - **Routing check**: `response["intent"] == entry["expected_intent"]` -> routing_correct: bool
       - **JSON validity check** (if `entry["expected_json_valid"]` is not null):
         For verify intent: check `response["verify_result"]` is not None and is a dict with expected keys
         For generate intent: check `response["generate_result"]` is not None
         For analyze intent: check `response["analyze_result"]` is not None
         -> json_valid: bool | None
       - **Retrieval check** (if `entry["expected_docs"]` is non-empty):
         Check if expected doc filenames appear in `response["citations"]` (check `source` or `filename` field in citation dicts)
         -> retrieval_hit: bool | None

    4. **Compute aggregate metrics**:
       ```python
       metrics = {
           "total_queries": len(results),
           "errors": count of status != 200,
           "routing_accuracy": correct_routing / total_routing_tests,
           "json_validity_rate": valid_json / total_json_tests,
           "retrieval_recall_at_5": docs_found / total_retrieval_tests,
           "avg_elapsed_s": mean(all elapsed times),
           "p95_elapsed_s": 95th percentile elapsed time,
       }
       ```

    5. **Output format**: Print results to stdout as formatted text AND save as JSON:
       - Print a summary table to stdout:
         ```
         === Eval Baseline Results ===
         Total queries:        32
         Errors (non-200):     2
         Routing accuracy:     78.6% (22/28)
         JSON validity rate:   60.0% (6/10)
         Retrieval recall@5:   50.0% (4/8)
         Avg latency:          12.3s
         P95 latency:          28.7s
         =============================
         ```
       - Save detailed results to `tests/eval/results.json` (gitignored)
       - Print per-query failures for debugging:
         ```
         FAILURES:
         - route-03: expected=verify got=search (routing)
         - json-02: verify_result is None (json_validity)
         ```

    6. **CLI interface**:
       ```python
       if __name__ == "__main__":
           import argparse
           parser = argparse.ArgumentParser(description="Run eval suite against agent API")
           parser.add_argument("--base-url", default="http://localhost:8001/api/v1", help="API base URL")
           parser.add_argument("--timeout", type=int, default=120, help="Per-query timeout in seconds")
           parser.add_argument("--category", default=None, help="Run only this category (routing/json_validity/retrieval)")
           args = parser.parse_args()
       ```

    7. **Exit code**: Exit 0 if all queries completed (even with failures). Exit 1 only if script itself crashes.

    8. Add `tests/eval/results.json` to `.gitignore` if not already present.

    IMPORTANT: Use httpx (already in requirements.txt), NOT requests. Use synchronous httpx.Client, not async.
    IMPORTANT: Do NOT import any app code. The eval script talks to the API over HTTP only.
