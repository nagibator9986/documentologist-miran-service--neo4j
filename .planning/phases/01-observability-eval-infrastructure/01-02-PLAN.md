       ```python
       """Debug endpoints for retrieval pipeline diagnostics.

       These endpoints expose internal retrieval stages without LLM calls,
       enabling threshold calibration and quality debugging.
       """
       from __future__ import annotations

       import logging
       import time
       from typing import Any

       from fastapi import APIRouter, Query
       from pydantic import BaseModel

       from ...core.config import get_settings

       logger = logging.getLogger(__name__)
       router = APIRouter(prefix="/debug", tags=["debug"])
       ```

    2. Add a response model:
       ```python
       class RetrievalStageResult(BaseModel):
           query_original: str
           query_for_embedding: str
           collection: str
           stages: dict[str, Any]   # each stage: {count, top_scores, items}
           thresholds: dict[str, float]  # active thresholds from config
           elapsed_s: float
       ```

    3. Implement `GET /debug/retrieval` endpoint. The endpoint must:
       - Accept `q: str` (query) and optional `collection: str` query params
       - Call the same tools the search agent uses, but DIRECTLY (not importing private search_agent functions):
         a. **Vector search**: Use `qdrant_search` tool with the query and collection
         b. **BM25 search**: Use `bm25_search` tool with the query
         c. **Graph search**: Use `neo4j_query` functions to get graph-enriched results
         d. **Reranking**: Use `reranker` tool on merged results
       - Return scores at each stage: count of hits, top-3 scores per stage, threshold values from config
       - Wrap everything in try/except so individual stage failures don't crash the endpoint
       - Track total elapsed time
       - NO LLM calls at any point

    4. The response structure should look like:
       ```json
       {
         "query_original": "...",
         "query_for_embedding": "...",
         "collection": "bank_knowledge",
         "stages": {
           "vector": {"count": 15, "top_scores": [0.87, 0.82, 0.79]},
           "bm25": {"count": 8, "top_scores": [12.5, 10.2, 8.7]},
           "graph": {"count": 3, "entity_count": 2, "law_count": 1},
           "merged": {"count": 20, "after_dedup": 18},
           "reranked": {"count": 5, "scores": [0.92, 0.85, 0.71, 0.45, 0.32], "logits": [...]}
       ```
